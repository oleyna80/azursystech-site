## 1. Цель страницы

Создать отдельную страницу AzurSysTech про автоматизацию бизнес-процессов с помощью ИИ-агентов, которая одновременно:

- привлекает клиентов на AI-автоматизацию
- объясняет услугу понятным языком
- усиливает SEO и AI-search видимость
- помогает AI-агентам и поисковым системам лучше понимать, что именно делает AzurSysTech
- конвертирует трафик в обращение через чат, WhatsApp и бриф

## 3. Позиционирование страницы

### Core positioning
AzurSysTech помогает малому бизнесу внедрять ИИ-агентов для обработки входящих заявок и обращений, первичной квалификации клиентов и автоматизации повторяющихся процессов.

Можно начать с одного процесса, не перестраивая весь бизнес.

Страница не должна обещать:
- полную автоматизацию “под ключ”
- автономных агентов без контроля
- замену сотрудников
- интеграции с любыми системами без анализа

## Section 4 — Главный use case

### Goal
Сделать core conversion block страницы.

### Suggested H2
**ИИ-агент для обработки входящих заявок и обращений**

### Required internal structure
#### 1. Что происходит без автоматизации
- заявки приходят хаотично
- часть запросов теряется
- нет единой структуры intake
- первый ответ зависит от занятости человека

#### 2. Что делает ИИ-агент
- принимает входящее обращение
- задаёт уточняющие вопросы
- помогает определить тип запроса
- собирает краткое summary
- передаёт задачу дальше по workflow

#### 3. Что остаётся человеку
- подтверждение важных решений
- сложные ответы
- ценообразование
- сроки
- финальное ведение клиента

#### 4. Какой результат получает бизнес
- более структурированный intake
- меньше ручной рутины
- быстрее первый этап обработки
- понятнее маршрут обращения

### Suggested visual logic
**Заявка → intake → qualification → summary → handoff**
