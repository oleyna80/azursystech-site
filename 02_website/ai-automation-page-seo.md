## 1. Цель SEO-спецификации

Зафиксировать SEO и AI-search основу для страницы `/ai-automation`, чтобы:

- страница была понятна поисковым системам
- страница была удобна для AI-агентов, которые выполняют поиск и цитирование
- контент имел чёткую semantic structure
- страница поддерживала конверсию, а не только трафик

## 9. AI-search / LLM-friendly structure notes

### Must include
- definitional paragraph near top
- explicit “what it is” block
- explicit “what it does” block
- explicit “what it does not do” block
- step-by-step workflow block
- direct FAQ questions
- practical use cases in plain language

### Must avoid
- long abstract branding statements
- hidden meaning
- weak heading hierarchy
- overuse of vague buzzwords
- too much stack/tool jargon

### Citation-friendly principle
Every major section should answer a direct business question in 2–5 clear paragraphs or a clear structured list.

## 18. SEO acceptance criteria

The SEO layer is valid if:
- the page has one clear intent
- title/H1/meta align to one main narrative
- H2/H3 map is clear and useful
- FAQ is direct and citation-friendly
- keyword use is natural
- page can rank and also convert
- page is readable by humans and AI agents without ambiguity
