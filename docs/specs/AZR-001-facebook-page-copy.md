# SPEC: AZR-001 Facebook Page Copy (Launch FR)

## Problem
Текущий файл `01_brand/facebook-page-copy.md` написан в RU и не полностью соответствует launch-потребности для локальной аудитории в Ницце (FR-first коммуникация).

## Scope
- Подготовить launch-ready версию Facebook Page copy на французском языке.
- Сохранить структуру документа (bio, about, pinned post, CTA, post ideas).
- Привести тексты к tone-of-voice из brand pack.
- Синхронизировать CTA с lead funnel (`site form` + `page messages`).

## Out of Scope
- Настройка Meta Ads Manager.
- Дизайн креативов/баннеров.
- Публикация постов и комьюнити-менеджмент.
- Автоматизация постинга.

## Requirements
1. География явно указана: Nice + 30 km.
2. Сегменты явно покрыты: particuliers + TPE.
3. Услуги соответствуют `00_strategy/offer-stack.md`.
4. Тон: simple/direct/reassuring/practical/local.
5. Нет непроверяемых обещаний, юридических гарантий и hard claims.
6. В каждом ключевом блоке есть понятный CTA.

## Acceptance Criteria
- AC1: `01_brand/facebook-page-copy.md` переведен в FR-first формат и содержит launch-ready copy для Facebook Page.
- AC2: В документе присутствуют и заполнены блоки: page name, bio, about, pinned post, CTA templates, first 10 posts.
- AC3: Контент явно покрывает both segments (`particuliers` и `TPE`) без смещения в один сегмент.
- AC4: CTA направляют в сообщения страницы или на форму сайта (`azursystech.fr`) без обещаний нереалистичных сроков/результатов.
- AC5: В header файла обновлены метаданные (version/status/language) под новое состояние драфта.

## Risks
- Слишком общий текст без конверсии в lead.
- Слишком технический текст для не-IT аудитории.
- Несогласованность с офферами и позиционированием.
