# Design brief — WB-2026-08-24-creation-site-internet-nice

## Meta

- Work Block: `WB-2026-08-24-creation-site-internet-nice`
- Surface: `/fr|en|ru/creation-site-internet-nice`
- Fidelity mode: `inspired-adaptation` of the existing AzurSysTech website
- Target audience: small businesses and artisans searching for website creation in Nice
- Business goal: make the existing, bounded website/intake offer discoverable and move qualified visitors to the existing brief/contact flow

## Design direction

- Preserve the existing fixed shell, dark graphite/light base contrast, teal/terra accents, type scale, rounded CTA language, spacing, and current asset vocabulary.
- Use one dominant idea per section: website types, intake functions, examples, process/prices, FAQ, CTA.
- Prefer editorial sections, dividers, lists, and media blocks over a new card system.
- Keep the visual result recognizably part of the current site; no global redesign or new image generation is in scope.

## Content and brand QA

- French H1 exact: `Création de site internet à Nice pour petites entreprises`.
- French title exact: `Création de site internet à Nice pour TPE & artisans | AzurSysTech`.
- All visible content is localized in FR/RU/EN.
- Portfolio items are existing examples, not client claims.
- Price references are “from” values only; no deadlines, guarantees, ROI, reviews, or invented results.
- CTA routes reuse the existing brief/contact and localized AI/portfolio paths.

## QA handoff

- Desktop and mobile: verify header/menu, readable contrast, tap targets, and no horizontal overflow.
- Route links: verify all localized internal links and sitemap entries.
- Structured data: compare JSON-LD to the same visible content object, especially FAQ pairs.
- Coder scope: only the approved Work Block write-set.
- Reviewer focus: content truthfulness, route/metadata integrity, unsupported claims, and regression risk.
- Verifier focus: all acceptance criteria plus Crash Test Gate and required commands.
