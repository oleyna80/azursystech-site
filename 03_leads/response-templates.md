## 1. Цель документа

Подготовить набор шаблонов ответов для AzurSysTech, чтобы можно было быстро и единообразно отвечать на:

- заявки с сайта
- сообщения из Facebook
- сообщения от частных клиентов
- запросы от малого бизнеса / TPE
- неполные обращения
- follow-up после тишины
- ответы после первичной квалификации

---

## 2. Основной принцип ответов

### Response philosophy
Ответы должны быть:

- короткими
- понятными
- спокойными
- практичными
- человеческими
- без лишнего техножаргона
- без жёстких обещаний по срокам и цене до уточнения задачи

### Main operational rule
Задача первого ответа — не “всё продать”, а:
1. подтвердить получение обращения
2. показать, что задача понятна
3. собрать недостающие данные
4. перевести клиента к следующему шагу

---

## 3. Response style guide

### Good tone
- спасибо за обращение
- короткое подтверждение
- 2–5 уточняющих вопросов максимум
- простой следующий шаг

### Avoid
- длинные технические объяснения
- перегруженные абзацы
- точную цену без данных
- слишком жёсткий “менеджерский” тон
- сухой robotic style

### Signature style
At launch, replies may be signed simply:
**AzurSysTech**

Later can include name + brand.

## 16. Operational rules for using templates

### Rule 1
Never send exact pricing promises unless task is clear enough.

### Rule 2
Do not send more than 5 clarification questions in the first reply.

### Rule 3
Adapt business vs home-user tone slightly, but keep one overall brand voice.

### Rule 4
If the client already gave enough details, do not repeat all questions mechanically.

### Rule 5
Use the shortest template that moves the lead to next step.
