# Memory Bank - AzurSysTech

Персистентная память для AI-агентов между сессиями.

## Как использовать

1. Перед началом сессии читать:
   - `memory_bank/context.md`
   - `memory_bank/progress.md`
   - `memory_bank/decisions.md`
2. После существенных изменений обновлять `progress.md`.
3. При новых архитектурных/process решениях обновлять `decisions.md`.

## Структура

- `context.md` - текущий контекст и фокус
- `progress.md` - журнал прогресса
- `decisions.md` - ADR и ключевые договоренности
