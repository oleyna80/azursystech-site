## 2. Общие правила для коротких объявлений

### Основной принцип
Короткое объявление должно за 3–5 секунд объяснить:

- кто ты
- чем помогаешь
- где работаешь
- кому это подходит
- как связаться

### Формула
**Проблема / услуга → для кого → география → CTA**

### Тон
- спокойный
- деловой
- простой
- без “агрессивных продаж”
- без перегрузки терминами

### Не делать
- не писать слишком длинно
- не перечислять 25 услуг в одном тексте
- не звучать как “универсальный мастер на всё”
- не обещать точную цену в каждом объявлении
- не использовать слишком много эмодзи

## 14. Рекомендации по использованию

### Для Facebook Page
Использовать:
- более структурированные варианты
- с нормальным CTA
- с упоминанием сайта

### Для групп
Использовать:
- более мягкие тексты
- меньше “рекламности”
- адаптацию под стиль группы
- меньше ссылок, если правила группы строгие

### Для комментариев
Использовать:
- короткие ответы
- перевод в личные сообщения или на сайт

### Для личных сообщений
Использовать:
- opener + 3–5 уточняющих вопросов

## 15. Acceptance criteria

Ads copy is valid if:
- тексты короткие и понятные
- есть варианты для бизнеса и частных клиентов
- есть мягкие версии для групп
- есть очень короткие формулировки
- тексты можно использовать почти без доработки
- есть понятный CTA
