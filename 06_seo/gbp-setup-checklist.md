## 1. Цель документа

Подготовить checklist для запуска и ведения **Google Business Profile** для AzurSysTech, чтобы:

- быстро запустить локальное присутствие в Google
- не пропустить обязательные поля
- связать профиль с сайтом azursystech.fr
- подготовить основу для локальных заявок и отзывов
- не строить GBP хаотично

---

## 2. Роль GBP в системе AzurSysTech

### Core role
Google Business Profile для AzurSysTech нужен как:

- локальная точка доверия
- источник переходов на сайт
- источник локальных запросов
- база для отзывов
- support asset для local SEO

### Main rule
GBP должен выглядеть:
- аккуратно
- правдоподобно
- локально
- без “полупустого” состояния
- согласованно с сайтом и брендом

## 3. Launch principle

На старте не нужно строить “идеальный профиль на все времена”.

## 7. Category strategy

### Goal
Выбрать категории, которые максимально соответствуют реальным услугам.

### Rule
Не выбирать слишком “широкие” или нерелевантные категории только ради охвата.

### Category selection logic
Primary category should reflect the core local service identity.
Secondary categories should reflect practical service clusters.

### Likely direction
Choose categories aligned with:
- IT assistance / computer support / computer repair / business IT support type logic
- local practical IT setup
- home + small business relevance

### Operational note
Final category choice must be made inside real GBP options list at setup time, using the closest available official Google categories.

### Rule
Prefer:
- one strong primary category
- a few relevant secondary categories
- do not overfill categories

## 8. Business description strategy

### Description goals
Business description should:
- explain who AzurSysTech helps
- explain what services are offered
- reflect Nice + 30 km
- sound practical, not corporate
- mention both TPE and home users

### Description should include
- computers / workstations
- Wi-Fi / local network
- printers
- onsite assistance
- small business support
- home user support
- Nice area relevance

### Description should avoid
- buzzwords
- AI-heavy positioning
- too much jargon
- exaggerated claims
- fake urgency

AzurSysTech — локальная IT-помощь в Ницце и рядом для малого бизнеса и частных клиентов. Настройка рабочих мест, компьютеров, Wi-Fi, локальной сети, принтеров и базовой IT-среды. Выездная помощь для небольших офисов, кабинетов, магазинов и домашних пользователей.

### Note
Later should be localized/adapted for actual GBP language context.
